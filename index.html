What it is

theBox is a desktop app. You type what you want done, for example "summarise the three contracts in my Legal folder and list the renewal dates", and watch it work in a live timeline. Where it needs something it was not given, it asks, in the timeline, and you answer with a click.

It asks nicely

Like installing a phone app: you see what a recipe can and cannot do, and why, before you install it. Risky actions ask every time, and you can switch any permission off later.

You choose the model

A model on your own computer, or one in your own AWS Bedrock account. For each task you pick Local only, Redacted cloud or Cloud.

Recipes teach it jobs

A recipe is packaged know-how: for example analysing a company's financial statements, or running a small content business without cameras. Recipes are signed and reviewed.

You can check what it did

Every action is written to a tamper-evident activity log, and a screen shows what left your computer, where it went and why.

How it works

  1. Install and open. Choose a model: one on your computer, or one in your own AWS Bedrock account.
  2. Describe the job, or pick a recipe and fill in its short form. Attach files by dropping them in.
  3. Watch and approve. The assistant shows its plan and each step. Anything beyond its own working folder asks first.
  4. Collect the result in the task's output folder, and reply to ask for changes.

Your model and your data

With a model on your computer, your task content stays on your computer. With a model in your own AWS Bedrock account, the text of your task is sent to that account, the app shows a clear cloud badge, and what happens to data there is decided by your AWS account and agreements. For each task you choose:

Recipes and the community (coming)

Recipes are signed packages. Each version goes through automatic checks, an AI review that only advises, and review by volunteers from the community, with a vetted sign-off for the risky ones. A community store, membership and a way for authors to publish are being built; the store is not open yet, and details and prices will be announced before anything is charged. You can try a recipe from a file in developer mode. In the meantime, 104 free recipes are built into theBox 0.4: browse them with their sources, then install from Discover.

Install on Linux

sudo apt install ./theBox-0.4.0-linux-amd64.deb
# or the AppImage:
chmod +x theBox-0.4.0-linux-x86_64.AppImage
./theBox-0.4.0-linux-x86_64.AppImage

On Ubuntu 24.04 and later the AppImage may fail to start because of the system's sandbox restrictions; use the .deb, or run the AppImage with --no-sandbox. A model on your computer needs working Vulkan or CUDA graphics drivers.

Install on macOS (testers)

  1. Unzip, then drag theBox into Applications.
  2. The app is not signed, so macOS will say it is damaged. Run this once in Terminal, then open it: 
    xattr -cr /Applications/theBox.app

The script sandbox for recipes has never been run on macOS, so recipe scripts are not network-isolated there.

Install on Windows (testers)

  1. Unzip the file anywhere (not inside the zip viewer), then run theBox.exe.
  2. Windows will warn about an unknown publisher: choose More info, then Run anyway.
Windows is not safe for sensitive work yet. About 40 of our permission and path tests fail when run on Windows, including the checks that protect folders such as ~/.ssh, so those protections are not verified there. Recipe scripts are refused on Windows because there is no sandbox. Please test it and tell us what you see.

Honest limits

Version 0.3.0 is the first release of the new assistant. It works end to end with a cloud model on Linux, and the permission system, activity log, task history and recipe installing are in place. The installers are not code-signed, and the Mac and Windows builds have never been run on a real machine.
  • The recipe store is not open yet, and the ratings, review and reviewer pages show sample data.
  • Models on your computer have not yet been tested in the new assistant, and the document-analysis tool from 0.2 is not connected to it.
  • Recipe scripts run in a Linux sandbox with no network access. On macOS the sandbox has never been run; on Windows scripts are refused, and several permission tests fail, so use Windows for testing only.
  • "Redacted cloud" masks only identifiers it can recognise, as described above.
