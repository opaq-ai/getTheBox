What it is

Many documents cannot be pasted into an online chatbot: audited accounts, client statements, contracts, internal reports. theBox is a desktop app built for exactly that work. You point it at a folder of documents, ask a question in plain language, and a local AI agent reads the files, computes the numbers with real code and produces an answer or a report.

Reads your documents

PDF, Word, Excel, CSV and plain text. Long reports are read page by page, so nothing is skipped.

Figures with page references

Every number is checked against the source text, and the page it came from is attached by the app, not guessed by the model.

Calculates, not guesses

Ask for totals, growth rates or comparisons and the agent writes and runs a small Python script, which you can read and approve.

Writes the report

Charts, tables and finished reports as HTML, PDF, Excel or images, saved in your own folder.

How it works

  1. Install and open. On first run the app checks your computer and recommends a language model that fits it.
  2. Download a model once. The app asks first. This single download from Hugging Face is the only time it goes online. You can also import a model file you already have.
  3. Test it. The app measures how fast the model runs on your machine and tells you plainly: Fast, Usable, Slow or Not suitable, with the time to read a 20-page document.
  4. Ask. Drop documents into the workspace, ask your question and watch the live progress as each part is read.

How your data is protected

ProtectionHow it works
Nothing leaves the machineThe model runs inside the app. Every network request from the app window is blocked, and the agent has no web tool.
Your files stay unchangedThe agent can read your input folder but cannot write to it. It writes only to an output folder and a scripts folder, and attempts to escape them are rejected.
You approve codeThe agent runs a script only after you allow it. On Linux scripts also run with no network access at all.
Numbers are checkedA figure that does not literally appear in the source page is dropped before it can reach the answer.

Not yet done, and worth knowing: on macOS scripts are not network-isolated (you approve each one), approved scripts can write anywhere your user account can, and downloaded model files are not checksum-verified yet.

Install on Linux

sudo apt install ./theBox-0.1.0-linux-amd64.deb
# or the AppImage:
chmod +x theBox-0.1.0-linux-x86_64.AppImage
./theBox-0.1.0-linux-x86_64.AppImage

On Ubuntu 24.04 and later the AppImage may fail to start because of the system's sandbox restrictions; use the .deb, or run the AppImage with --no-sandbox. The app needs working Vulkan or CUDA graphics drivers (on a machine without a graphics card, install mesa-vulkan-drivers).

Install on macOS

  1. Unzip, then drag theBox into Applications.
  2. The app is not signed yet, so macOS will say it is damaged. Run this once in Terminal, then open it: 
    xattr -cr /Applications/theBox.app

Check your download

The release includes SHA256SUMS.txt. Compare it with your file:

sha256sum theBox-0.1.0-linux-amd64.deb     # Linux
shasum -a 256 theBox-0.1.0-mac-arm64.zip   # macOS

Which model should I use?

Your computerModel
8 GB memory, no graphics cardQwen2.5 3B: fast, but makes arithmetic mistakes. Treat its numbers as drafts.
16 GB memory (most laptops)Qwen2.5 7B: the smallest model that reliably recovers from its own errors.
24 GB+ with an NVIDIA graphics card or Apple SiliconQwen2.5 14B: clearly better analysis.
32 GB+ with a strong graphics cardQwen2.5 32B: the best quality offered.

The app picks for you and tests the result. Speed depends mostly on memory bandwidth: on a laptop with integrated graphics, a 20-page report took roughly 3 to 14 minutes with the 7B model.

Honest limits

This is an early release. The Linux build has been run end to end. The macOS builds were assembled on Linux and have not yet been run on a real Mac. Neither platform's installer is code-signed. Scanned PDFs (images of pages) are not supported yet because there is no text recognition. A local model can still be wrong, so review anything that matters.

Found a problem, especially on a Mac? Please open an issue and say which system you use. Do not attach sensitive documents.
